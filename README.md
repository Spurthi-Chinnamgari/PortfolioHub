# PortfolioHub

> **Create once. Manage easily. Showcase everywhere.**

PortfolioHub is a full-stack SaaS platform that allows developers to create, manage, and publish professional portfolios using predefined, professionally designed themes—without writing frontend code.

It solves the common problem of developers having to manually build and update portfolio websites whenever they want to showcase new projects, skills, certifications, or experience. PortfolioHub provides a centralized workspace where users can manage their professional information, select a suitable theme, and publish it through a shareable public portfolio.

## ✨ Key Features

-  Secure user registration and login with JWT authentication
-  Personal portfolio management
-  Project management
-  Skills and skill-category management
-  Certificate management
-  Work experience management
-  Social media and professional link management
-  Contact form for public portfolios
-  Manage and mark received contact messages as read
-  Public portfolio pages with shareable URLs
-  Responsive and modern user interface
-  Protected APIs and authenticated portfolio management
